### 年齢の確定方針（#1）
- 保存範囲（満15〜100歳）は変更なし。必須登録に変わり、NULLへは戻せません。既存会員の生年月日は推測して埋めません。
- 公開条件は別判定 `stylist_salon_publishable(user_id)`（一覧関数・画像ポリシー・開示依頼・スカウト送信先が参照）。正確な満年齢で判断し、年代表示でも未成年の保留は回避できません。保留の解除は運営のSQL（別承認）: `update public.feature_pauses set paused=false where feature='minor_salon_public';`
- 実年齢の開示依頼: 単位は**店舗**。依頼できるのは `can_manage_store_hiring` の人、承認後に年齢を見られるのは `is_store_accessible` の人（その店舗のみ）。
- 検証: `0070_verify.sql`（公開判定の境界C11〜C21ほか）、`0070_verify_age.sql`（必須登録・表示方法・開示依頼・店舗/他人の拒否・18歳境界・誕生日・非公開・スカウト）、`age_concurrency_verify.sh`（連打・同時承認/辞退）、`mutation_check_age.sh`（誤実装を検出できること）。
