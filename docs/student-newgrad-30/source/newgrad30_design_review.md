# 新卒向け共通30問：配点・8タイプ設計 v0.1

作成日：2026年11月16日。作成：GPT。状態：レビュー用の初期設計。質問・アプリ・DBの実装と本番適用は行っていない。

## 1. 固定する体験と範囲

共通入口→30問→キャラクターを含む結果→登録を維持する。1問目の新卒選択で新卒版を使う。別入口、診断前の登録、既存15問への誘導は追加しない。経験者版の質問・配点・保存済み結果は変更しない。新卒版は独立した診断バージョンで保存する。0075は保留。

1問目の「新卒・これから美容師として働く」は在学中または卒業後で、美容師としての実務経験がない人を想定する。学校での実習やウィッグ練習は実務実績と扱わない。サロン勤務経験のあるアシスタントは既存側を選ぶ案。診断の選択でプロフィールの立場を自動変更しない。

## 3. 採点規則

- 30問すべて回答する。1問目（分岐）と3問目（興味の参考情報）は、全選択肢を分子・分母から除外する。3問目の「まだ決まっていない」は回答済みであり、低評価・既定タイプ・平均値補完にしない。
- 残る28問が採点対象。各問の選択肢はすべて同じ加点総量。通常項目は合計2点、似た希望項目は合計1点。後者は4・5・9・13・16・17・19・21・27・29・30問。希望だけを多重に数えないための初期仮説であり、検証済み係数ではない。
- 2点は主な傾向一つ、1+1点は二つの傾向。希望項目では1点または0.5+0.5点。負の加点は使わない。
- 軸別スコア＝獲得点÷新卒版の各問最大点の合計×100。最後に正数の四捨五入で整数化。分母は回答内容で変えない。
- 未選択は保存拒否。未選択を0点にして進めない。市場価値・年収・経験者の経験分析は計算・表示しない。
- 「発信しない」「先生へ相談をつなぐ」等の一回答から消極性・能力不足を断定しない。配点は質問文脈に基づく仮説で、説明文は回答一つから人格を決めない。

## 4. 8タイプの分類と表示

8タイプの計算係数は添付原本 `core-types.ts` の `CORE_TYPE_WEIGHTS` と `0004_core_types.sql` を用いる案。各軸を上記の新卒向けの意味として解釈する。8タイプごとの順位ではなく、同じ重み表を使うキャラクター分類。12タイプは既存保存の内部互換情報としてのみ扱う案で、経験者向け12タイプ説明を新卒画面やAI入力へ流用しない。

結果画面の見出しは「あなたのタイプ」。共通注記は「回答から見える、興味や取り組み方の傾向です。現在の技術力や、将来の成果を評価するものではありません。」。新卒向けであることを分かるようにする。キャラクター名・画像・8タイプコードは維持する。


### 指名磁石／ジマ

**人とのつながりを、自分らしく届けたい。**

相手の気持ちを大切にしながら、自分の作品や人柄も伝えていきたい傾向です。今の指名数や接客実績を表す結果ではありません。

- 表示する傾向：話を聞ける・自分の言葉で伝えたい
- 試してみること：友達へのスタイル提案で、理由を短く説明してみる。
- 表現上の注意：接客実績がある、すでに指名されるとは書かない


### 愛されエース／サクラ

**丁寧に学び、周りと一緒に育っていく。**

基礎を大切にし、人の気持ちや仲間との協力にも関心を向ける傾向です。上手さや人気が証明されたという意味ではありません。

- 表示する傾向：丁寧に取り組みたい・支え合いたい
- 試してみること：練習の振り返りを一つ決め、友達と共有してみる。
- 表現上の注意：技術も人柄も本物、誰からも好かれるとは書かない


### 似合わせマスター／ミラー

**仕組みとデザイン、どちらも知りたくなる。**

形や手順の理由と、色・雰囲気などの表現の両方を考えたい傾向です。似合わせ技術を習得済みという評価ではありません。

- 表示する傾向：理由を知りたい・表現を工夫したい
- 試してみること：好きな髪型を一つ選び、形と雰囲気の理由を書き出してみる。
- 表現上の注意：マスターという名称はキャラクター分類名。熟練の認定ではない


### トレンドメーカー／フレア

**好きな世界観を、形にして伝えたい。**

デザインや新しい表現に興味があり、作品を人に届けることにも関心が向きやすい傾向です。流行を生み出す実績の評価ではありません。

- 表示する傾向：表現に惹かれる・発信を工夫したい
- 試してみること：好きな作品を三つ集め、共通する色や雰囲気を整理してみる。
- 表現上の注意：将来有名になる、センスが優秀とは断定しない


### 癒しのカリスマ／リーフ

**相手の気持ちと、居心地を大切にしたい。**

相手の話を聞くことや、相談しやすい関係、支え合える雰囲気を大切にする傾向です。内向的か外向的かを決める診断ではありません。

- 表示する傾向：気持ちを理解したい・安心できる関係をつくりたい
- 試してみること：共同練習で、相手が困っていることを一つ聞いてみる。
- 表現上の注意：必ず人を癒せる、接客が得意とは書かない


### リピートキング／レオ

**一つずつ確かめ、信頼につなげたい。**

丁寧な取り組みと相手への配慮を大切にし、試して改善することにも関心がある傾向です。リピート率や顧客満足の評価ではありません。

- 表示する傾向：丁寧に確かめたい・改善していきたい
- 試してみること：練習ごとに、できた点と次に試す点を一つずつ残してみる。
- 表現上の注意：リピートされる実力がある、顧客が定着すると書かない


### 未来のエース／ルーチェ

**まず動いて、自分の道を見つけたい。**

新しいことを試し、経験しながら学ぶ方向へ気持ちが向きやすい傾向です。他のタイプより伸びしろが大きいという順位ではありません。

- 表示する傾向：試して学びたい・自分から動きたい
- 試してみること：取り組める小さな課題を一つ選び、先生と相談して試してみる。
- 表現上の注意：誰より伸びる、ほかより将来性があるとは書かない


### ブランドビルダー／アーク

**自分の表現を、仲間と一緒に育てたい。**

作品や考えを伝えること、周りと協力して新しいことに取り組むことに関心がある傾向です。経営能力やリーダーの適性を保証しません。

- 表示する傾向：伝える工夫をしたい・協力して進めたい
- 試してみること：友達と小さな作品テーマを決め、役割を分けて形にしてみる。
- 表現上の注意：経営向き、組織を率いる才能が確定とは書かない


## 5. 同点と僅差

- 軸を整数化した後、既存式でタイプの加重和を求め、小数1桁へ正数四捨五入する。JSとPostgreSQLの浮動小数・丸めを含め一致検証する。
- 同点は固定のコード順で内部首位を決定する案：shimei_jishaku, aisare_ace, niaiwase_master, trend_maker, iyashi_charisma, repeat_king, mirai_no_ace, brand_builder。新卒版で明示し、経験者の既存結果を並べ直さない。
- 首位同点は「一つに決まりませんでした」ではなく、主キャラクターと第二候補を同列に近い扱いで見せる。表示例：「この2タイプの傾向が近く出ています」。3者以上同点なら「複数のタイプが同程度」と明示し、一覧を展開できる設計案。
- 差2.0以内は第二候補を補足する暫定案。2.0は表示運用の候補値で、統計的な確信度や心理学上の境界ではない。初期検証では対象が多いため、表示量を実画面で確認する必要がある。
- 同点解消のために乱数、現在時刻、ユーザーIDで加点しない。3問目も同点解消に使わない。
- 添付原本のDBは同点時の二次ソートなし、TSは定義順。よってこの一致はまだ実装済みではない。既存保存関数を勝手に編集せず、新卒版だけの分岐など新しいDB草案が必要かをClaudeが調査する。DB変更なしを前提にしない。
