## アプリの変更（`app_change_summary.md` に差分の要約）
- 共通入口: 診断1問目に5つ目「新卒・これから美容師として働く」。1問目の回答で2問目以降のセットが決まる。
- 採点: 新卒版は1問目・3問目を除く28問。市場価値・年収は null（経験年数2の既定値を使わない）。12タイプの内部値は保存互換のためだけに計算し、画面・AIには出さない。
- 送信: 版名と質問IDを添え、サーバーが1問目の回答から公式の版を決めて照合する。
- 引き継ぎ: 保存された版の質問・検証・計算を使う。Cookieを消すのは期限切れ等が明確なときだけ（一時障害・版不明では保つ）。
- 結果画面・マイページ・AI解説: 新卒向けの表示と指示。能力・経験・年収・市場価値・才能グラフ・経験者向け12タイプ文を出さない。プロフィールの立場は診断から自動変更せず、不一致のときだけ案内。
- 新卒入口スイッチ `NEWGRAD_ENTRY_ENABLED`（既定無効、`compat_and_rollback.md`）。旧15問の新規保存はサーバーで停止（表示・履歴は不変）。
