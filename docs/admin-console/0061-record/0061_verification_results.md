## 要望6項目との対応
1. 送信者ごと30件/時間: 全スレッド横断で数え、送信者ロックで並行時も超えない（C1）
2. 送信ID: 作成・管理者投稿・受信者返信。再送は同結果、内容違いは拒否、通知は重複しない
3. 異動後: 管理者は閲覧・完了・再開が可能、元窓口は閲覧・返信不可。作成時検証のみINSERTで実施
4. 権限: 8表と関数を PUBLIC/anon/authenticated/service_role から明示revoke、必要分のみgrant。実効権限を検査
5. 並行: 管理者投稿/返信/完了/再開を 送信者→リクエスト→スレッド行 の順で統一（C2〜C6）
6. 巻き戻し: 未使用時の完全削除とデータを残す停止/再開に分離
