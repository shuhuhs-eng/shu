## 検証で確認したこと（ローカルDB）
- 運営者以外（未ログイン・一般サロン・店舗担当者・他社・美容師）は、0060の4関数すべてで拒否。
- 検索（会社名・店舗名・担当者名・登録メール）、都道府県・未設定・公開状態の絞り込み、店舗プロフィールの所在地を店舗値より優先、勤務希望（自由記述）と居住地の別検索、`%` を特殊文字として扱わない、件数の上限。
- 連絡の閲覧・返信: 会社オーナー/管理者/採用管理者、対象店舗の店長・採用担当のみ。閲覧のみ・担当店舗のないエリア担当・同社の別店舗・他社は不可。美容師宛は本人のみ。
- 直接のテーブル参照は anon/authenticated とも拒否。招待の重複、見学案件の重複、二重請求、13店舗以上・個別見積の請求は確定・決済待ちに進めない、運営確認なしでは確定できない、決済の同時進行は1件、決済通知の重複は拒否、カード情報の列が無い。
