## 仕様と実装の対応
| 仕様 | 実装 |

| 現役・新卒に期間欄を出さない | 画面で出さない／サーバー・DBでも拒否 |

## 既存データの保護（0076はデータを1行も更新しない）
- 旧3項目（卒業の区分・就業開始・免許）の保存済み値: **削除も変換もしない**。v4は触らない。現役・ブランクの行に残っていてもよい（制約を緩和）。画面・サロン側には出ない。
- 卒業月が3月/10月以外の新卒（既存）: **丸めない**。編集画面は年を残し月を未選択で開き、「選び直してください」と案内。選ぶまで保存できない。DBの月の検査は「卒業年月または立場を新しく書くとき」だけ働き、既存行の他の更新（自己紹介など）は拒否しない。
- 旧値（未設定NULL・美容学生）は変換しない（従来どおり）。
