# 運営マニュアル作成用資料（草案・2026-11-28）
※本番未適用・未公開。下記は実装コードとローカル検証（疑似DB）から作成。**画面写真は未取得**（認証つき運営画面は実Supabaseのあるステージング環境が無いと撮影できないため。巻末参照）。

## 1. 機能フラグ（すべて既定OFF。Vercel環境変数で "1" のときのみ有効）
| 変数 | 有効にすると出るもの |
|---|---|
| SCOUT_LEDGER_ENABLED | /admin/scout-ledger、登録区分、期限切れ日次処理(cron)、/terms の料金表 |
| SALON_ACCOUNT_ISSUE_ENABLED | /admin/salons/issue（サロンアカウント発行）。同時に /signup/salon の一般新規登録を閉じる（案内表示・server actionも拒否）。招待のパスワード設定導線は維持 |
| MANUAL_BILLING_ENABLED | /admin/manual-billing（手動請求・入金管理・請求書PDF） |
| （DB設定）salon_card_required | カード未登録サロンの業務停止。**OFFのまま**（責任者のみ変更可） |
| （DB設定）auto_charge_enabled | 採用料の自動請求。**OFFのまま** |

## 2. 操作経路（責任者）
1. **サロンアカウント発行＋登録区分選択**: 運営ナビ「会社・店舗」→「サロンアカウントを発行」(/admin/salons/issue)。会社名・担当者名・メール・登録区分（通常登録/キャンペーン登録）を入力→発行。担当者へパスワード設定メールが届く。再送・取消は同画面の発行履歴から。
2. **既存法人の登録区分設定**: スカウト台帳(/admin/scout-ledger)→対象法人の行→法人詳細(/admin/scout-ledger/[法人ID])→「登録区分」フォーム→区分選択→保存。保存時に初回スカウト（通常10件／キャンペーン5件）が1回だけ付与される（法人1回・再設定は不可）。一覧上部の「登録区分が未設定の法人が N 件」で未設定を確認。
3. **登録料**: 本部が直接徴収。システムには区分と金額の記録のみ（決済機能なし）。
4. **スカウト期限切れ**: 毎日 JST 0:10 に自動処理（/api/cron/scout-expiry）。実行履歴は /admin/scout-ledger 下部「失効実行履歴」。
5. **見学・体験料／採用料の手動請求**: /admin/manual-billing →「請求を作成」（対象の見学請求または採用予定を選択→支払期限）→請求番号 BR-年-連番 が採番。入金は請求詳細で「入金を記録」（日付・金額）。全額入金で見学請求=支払済／採用=請求済になる。※画面の状態名: 「請求済み（未入金／一部入金）」＝請求書を発行しただけ、「入金済み」＝全額の入金を記録済み（別の状態）。誤記録は「入金を取消」（履歴は消えず取消行が追加）。請求の取消は「無効にする」。手動請求が有効な間はカード自動請求は止まる。
5b. **請求書PDFの発行**: 請求詳細で「請求書PDFを発行」。発行事業者・振込先（/admin/issuer-settings）と会社の請求先情報が未設定だと発行できない（不足項目が表示される）。発行後は変更不可。番号は既存の請求書と共通の連番。
5c. **サロン一般登録の閉鎖**: /admin/salons/issue 上部「サロンの新規登録（認証側）」→「一般登録を閉じる」。閉じると本部発行のアカウントだけが作れる（美容師登録・既存サロンのログインは影響なし）。
6. **二重決済・誤請求・返金など支払い例外**: 自動返金は一切しない。/admin/stripe（カード決済の確認）と /admin/integrity（整合性チェック）で個別確認。法人詳細(/admin/scout-ledger/[法人ID])に該当時は警告と /admin/stripe/[法人ID] へのリンクを表示。
7. **カード必須化**（実施前）: 影響確認SQL 0119（読み取り専用）で停止対象数を確認→責任者がDB設定を変更（本番承認後）。
8. **規約・料金表示**: 規約本文は /admin/legal から公開（本番操作・法務確認後）。料金表は /terms に自動表示（SCOUT_LEDGER_ENABLED時）。

## 4. 画面写真について（未取得・理由と次の手順）
- 運営画面はすべてログイン（責任者）＋Supabase実データが必要。当環境にはステージングSupabaseの接続情報が無く、撮影不可。
- 撮影用の最小手順: ステージングで3フラグをON→責任者でログイン→上記の経路の順に画面を開き、各画面を保存。撮影対象: ①/admin/salons/issue ②/admin/scout-ledger（未設定件数のお知らせ・失効履歴） ③法人詳細の登録区分フォーム ④/admin/manual-billing 一覧・詳細 ⑤/terms 料金表。
- 個人情報が写り込む場合はダミーデータで撮影すること。
