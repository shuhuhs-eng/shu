# 利用規約 第5条の改定案（草案・要法務確認・未公開）
現行 第5条（料金、成功報酬および請求）に、次の条項を追加／置換する案。公開は /admin/legal（責任者）から。本文を変えたら version を上げる（同意の再取得が発生）。

5-1 登録料: サロン・会社の登録料は、通常登録は税込33,000円、キャンペーン登録は0円とし、運営者が登録時に区分を定める。登録料は運営者が別途直接お受けする。
5-2 初回スカウト: 登録時に、通常登録は10件、キャンペーン登録は5件のスカウトを、会社につき1回に限り付与する。
5-3 月額利用料: 無料。
5-4 スカウトの追加購入: 10件単位、税込11,000円（税抜10,000円）。購入分は購入日から1年間有効で、期限を過ぎた未使用分は失効する。購入後の返金は、運営者に責めのある場合を除き、原則として行わない。
5-5 見学・体験料: 税抜50,000円（税込55,000円）とし、運営者が請求書で請求する。
5-6 採用料: スタイリスト税抜550,000円、アシスタント税抜450,000円。入社成立時に発生し、請求書または運営者の定める方法で支払う。
5-7 二重のお支払い・誤請求など: 運営者が確認のうえ個別に対応する（自動での返金は行わない）。

要確認: 5-4「責めのある場合を除き」の文言／消費税・インボイス表記／特商法表記・中途解約時の扱い／1年の起算（購入日の翌日0時か、購入日同時刻か）。
