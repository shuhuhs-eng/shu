# サロンらしさ 入力UX設計

Beauty Reach「サロンらしさ」（`docs/salon-personality-design.md` Ver2）の入力体験設計。
**本書は設計文書のみであり、実装コード・SQL・マイグレーションは一切含まない。**

## 0. 改訂履歴（Ver1→Ver2の変更点）

1. **実態（current_culture）と理想（aspired_culture）を分離**：初回オンボーディングは「実際に起きている行動」のみを聞き、「育ってほしい姿」「目指す文化」は追加プロフィール側の別セクションに分離した。将来のAIマッチングでも両者を同じ値として扱わない
2. **方向性型CultureAxisのラベルを中立化**：どちらかが優れて見える表現（家族的／プロフェッショナル等）を避け、両端とも価値のある選択として伝わる言い回しに変更
3. **完了率表示をメリット先行に変更**：「◯%」の数字だけを強調せず、「入力するとマッチング精度が上がる」という便益を先に伝える表現にした

---

## 設計方針

- 最初から全部聞かない。初回は骨格だけを掴み、結果を早く見せてから追加入力へ誘導する
- 自由記述に頼らない。行動の選択（4択・スライダー）で本音を拾う
- 役割によって聞き方を変える（当事者として聞くか、観察者として聞くか）
- 評価しない。個性のマッピングとして見せる
- **「今」と「これから」を混同しない**。実態はそのまま実態として記録し、理想を上書きしない

---

## A. 初回5分オンボーディング（実態のみを聞く）

目標：**7ステップ・5分以内**。すべて「現在、実際に起きていること」を聞く質問で構成し、理想・将来像は一切含めない。

| Step | 内容 | 入力形式 | 実態/理想 |
|---|---|---|---|
| 0 | 回答者選択（オーナー・代表者／店舗責任者／採用担当／その他） | 4択カード | — |
| 1 | 新人がミスをしたとき、実際に最初に何をしているか | 4択 | 実態 |
| 2 | 意見が割れたとき、実際には誰が決めているか | 4択 | 実態 |
| 3 | お客様との実際の距離感 | スライダー（中立表現、D節参照） | 実態 |
| 4 | SNS投稿を、実際にスタッフ個人へどこまで任せているか | 4択 | 実態 |
| 5 | 新しい技術・提案が出たとき、実際にどう反応しているか | 4択 | 実態 |
| 6 | 今、実際に大切にしている価値観トップ3（優先順位選択） | 優先順位選択（12候補） | 実態 |
| 7 | 今のサロンの雰囲気を一言で（自由記述・任意） | テキスト・スキップ可 | 実態 |
| → | 結果画面を即表示 | | |

すべて「今、実際にどうしているか」で統一し、「そうありたい」という願望が紛れ込む質問文（例：「大切にしたい」）は使わない。6は「今、実際に大切にしている」という現状認識として明確に言い切る。

---

## B. 追加プロフィール（実態の深掘り＋理想は完全に別セクション）

初回完了後、結果画面から任意で誘導。**「実態の深掘り」と「理想・将来像」を画面上も明確に分けたセクションにする**（同じフォームに混在させない）。

### B-1. 実態の深掘り（current_cultureの追加項目）

| 項目 | 入力形式 |
|---|---|
| マネジメントスタイル（実際の意思決定の様子） | スライダー |
| チームの関係性（実際の役割分担の様子） | スライダー |
| 今回の募集で重視したい経験・強み | 4択＋自由記述任意 |
| 今、チームに足りていないと感じる強み | 才能軸からの簡易チェック |

### B-2. 理想・将来像（aspired_culture。current_cultureとは別データとして保持）

| 項目 | 入力形式 |
|---|---|
| どんな美容師に育ってほしいか | 4択＋自由記述任意 |
| どんなサロンにしていきたいか（将来像） | 自由記述（任意、短文） |
| これから大切にしていきたい価値観トップ3 | 優先順位選択（現在の価値観と同じ12候補、**別回答として保持**、現在の回答と同じである必要はない） |
| 会社として美容師にどう育ってほしいか（複数店舗を持つ場合のみ表示） | 4択＋自由記述任意 |

**データ設計上の要件**：`current_culture`（実態）と`aspired_culture`（理想）は、同じ値として扱わず、常に別々に保持する。将来のAIマッチングでは、「今の実態」と「目指す方向」の両方、あるいはそのギャップ自体も相性判断の材料になりうるため、上書き・平均化・混在は行わない（命名は仮でよいが、この区別自体は要件とする）。

---

## C. 回答者別の質問分岐

分岐ルールは1つ：`owner_representative`・`store_manager`は当事者として一人称で、`recruiter_hr`・`other`は観察者として聞く。

| 質問の骨子 | 当事者向け | 観察者向け |
|---|---|---|
| 新人のミス対応 | 「新人がミスをしたとき、あなたが最初にすることは？」 | 「新人がミスをしたとき、店舗責任者が最初にすることは？」 |
| 意思決定 | 「意見が割れたとき、最終的にあなたが決めますか？」 | 「意見が割れたとき、最終的に誰が決めていますか？」 |
| マネジメントスタイル | 「あなたは実際にスタッフとどう関わっていますか？」 | 「店舗責任者は実際にスタッフとどのように関わっていますか？」 |
| 理想像（育ってほしい姿） | 「あなたは美容師にどう育ってほしいですか？」 | 「店舗責任者・会社は、美容師にどう育ってほしいと考えていますか？」 |

理想・将来像の質問（B-2）も同じ変換ルールで一人称／観察者を切り替える。

---

## D. 各質問の入力UI（方向性型スライダーの中立化）

| CultureAxis | 両端の表現（改訂後） |
|---|---|
| `customer_relationship_style` | 「親密な関係を重視」 ⇔ 「適度な距離感を重視」 |
| `team_collaboration_style` | 「役割が明確」 ⇔ 「フラット」（維持） |
| `management_style` | 「オーナー主導（意思決定が速い）」 ⇔ 「権限委譲（現場の裁量が大きい）」（両端に短い補足を添え、どちらも長所であることを示す） |

いずれのスライダーも、中央に「どちらも良し悪しではなく、サロンの個性です」という一言を常時添える。両端のラベルは形容詞の強弱ではなく、**それぞれ独立した価値として並列に見えるフレーズ**を使う。

その他の入力形式（4択・優先順位選択・自由記述）はVer1設計から変更なし。

## E. サロンらしさ結果画面（評価しない・中立表現に限定）

```
┌─────────────────────────────┐
│ このサロンの「らしさ」は          │
│                                │
│ 『挑戦を歓迎し、                 │
│    個人の色を大切にするチーム』    │
├─────────────────────────────┤
│ 6つのらしさ                     │
│                                │
│ 教育支援      ●●●●○           │
│ 挑戦への開放性 ●●●●●           │
│ 個人ブランド支援 ●●●○○         │
│  ※数値の大小は優劣ではなく特徴の強さを表します │
│                                │
│ 親密な関係を重視 ●──○ 適度な距離感を重視│
│ 役割が明確      ○──● フラット        │
│ オーナー主導     ●──○ 権限委譲        │
│  ※どちらも良し悪しではなく、サロンの個性です │
├─────────────────────────────┤
│ 今、大切にしている価値観           │
│  ① 挑戦を後押しする文化           │
│  ② チームの信頼関係              │
│  ③ お客様との長期的な関係         │
├─────────────────────────────┤
│ （理想・将来像を入力済みの場合）    │
│ これから目指したい文化            │
│  「もっと個人の発信を後押ししたい」  │
└─────────────────────────────┘
```

- ランキング・偏差値・「業界平均より◯◯」等の比較表現は一切使わない
- 度合い型はドット等の中立的な表現、方向性型は左右の位置のみで示す
- 「今、大切にしている価値観」（実態）と「これから目指したい文化」（理想）は、**画面上も明確に分けて表示**し、混同しない
- 末尾に「この結果は美容師とのマッチングに活用されます（今後実装予定）」を添える

## F. 完了率を高める仕組み（メリット先行）

**「◯%」を主役にせず、入力する便益を先に伝える。** ％表示は補助情報として添えるにとどめる。

```
サロンらしさ
80%
あと2項目入力すると、
美容師との相性をより正確に分析できます。
```

| 仕組み | 内容 |
|---|---|
| 途中保存 | 各ステップ回答時点で自動保存 |
| 後で続ける | 離脱しても次回ログイン時に続きから再開できる導線 |
| 便益ベースの進捗表示 | 「あと◯項目で〜できます」を主文言にし、％は補助として小さく併記 |
| 先に結果を見せる | 初回7問だけで結果画面（E）を表示し、入力の価値を実感してから追加入力へ誘導 |
| 再訪起点 | マイページに「サロンらしさを充実させる」カードを常設 |
